# Frontend Development

## Instructions

1. **Page structure**
   - Semantic HTML structure
   - Clear layout hierarchy
   - Responsive containers

2. **Components**
   - Reusable and isolated components
   - Clear props and state handling
   - Consistent naming conventions

3. **Layout & styling**
   - Flexbox and grid-based layouts
   - Responsive design (mobile-first)
   - Clean and consistent spacing
   - Scalable CSS or utility classes

## Best Practices
- Keep components small and focused
- Separate layout, logic, and styling
- Ensure accessibility basics (labels, contrast)
- Avoid inline styles unless necessary
- Maintain visual consistency across pages

## Example Structure
```html
<main class="page">
  <header class="page-header">
    <h1>Page Title</h1>
  </header>

  <section class="content">
    <div class="card">
      <h2>Component Title</h2>
      <p>Component content</p>
    </div>
  </section>
</main>
